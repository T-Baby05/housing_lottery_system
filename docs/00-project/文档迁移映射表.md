## 1. 文档目的

本文用于记录当前历史文档到标准文档目录的迁移关系，避免在整理过程中丢失上下文、破坏引用或重复建设。

本轮策略：

1. 先建立映射，不立即删除历史文档。
2. 优先复制/整理为标准版文档，再考虑是否归档旧文档。
3. 对已经被标准版替代的历史文档，后续在原文顶部标注迁移目标。
4. PDF、HTML 等材料作为原始素材保留，可在标准文档中引用。

- 不直接删除历史文档。
